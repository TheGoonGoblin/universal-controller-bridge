# App artwork

Generated with the built-in image-generation tool. Selected project asset:

- assets/brand/icon0.png — 512 x 512 RGB home-screen icon.
- src/app/ui_assets.hpp — native icon pixels and DejaVu antialiased text atlas.
- assets/fonts/DejaVuSansMono.ttf — font source, license in licenses/DejaVu.txt.

The icon and font atlas are embedded in the app; there is no runtime image or
font dependency. The source asset generator is tools/prepare-ui-assets.py.

Final image-generation prompt:

Use case: logo-brand. Asset type: final square PS5 home-screen app icon for Universal Controller Bridge (UCB). Design a premium, instantly readable sculpted 3D game-controller bridge emblem: one unified original controller silhouette with an elegant connecting cyan arch/orbit, representing controllers connecting across systems. Polished midnight navy rounded-square tile, luminous electric-blue/cyan edge lighting, small mint-green accent, smooth metallic/glass surfaces, tasteful depth, restrained soft glow. Center emblem large with generous safe margins so it is readable at small sizes. A concise 'UCB' wordmark integrated below emblem, exactly UCB. Professional console utility branding, clean minimal composition, no Sony or Xbox logos, no trademark controller button glyphs, no extra text, no watermark. Square 1024px composition. Fully opaque background.
